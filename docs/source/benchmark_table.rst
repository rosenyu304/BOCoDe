Benchmark table
===============

An interactive, filterable table of every problem in BoCoDe. Toggle the buttons to
filter by application, objectives, constraints, and variable type; type to search by
name; click a column header to sort. This mirrors ``bocode.list_problems(...)`` — the
same filters you would pass in code.

The table is generated from the per-problem metadata
(``tools/render_docs_table.py``); see :doc:`basic_user_guide/filtering` for the
programmatic API.
