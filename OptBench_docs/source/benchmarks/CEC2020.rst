CEC 2020 Benchmarks
=================

The Engineering benchmark collection contains non-convex constrained optimization problems from the real world and some baseline results.
More information can be found in the `2020-RW-Constrained-Optimisation GitHub page <https://github.com/P-N-Suganthan/2020-RW-Constrained-Optimisation/>`_.

Example Usage
------------

.. code-block:: python

    import optbench
    import torch

    # Create a Botorch benchmark problem
    problem = optbench.CEC2020_RW_Constrained.CEC2020_p1()
    
    # Get problem information
    bounds = problem.bounds
    
    # Evaluate at a point
    x = torch.Tensor([[0.0] * problem.dim])
    inequality_constraints, equality_constraints, values = problem._evaluate_implementation(x)
    
    print(f"Heat exchanger network design function value at origin: {values[0]}")
