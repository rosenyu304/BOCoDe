# TOPFuns

We present TOPFunEngineering (Torch-based OPtimization Functions for engineering), a Python PyTorch-based library that contains the most comprehensive suite of engineering design problems and interface of popular synthetic optimization problems. Our goal is to provide not only a python surrogate (Bayesian) optimization benchmark library, but also allows the PyTorch interface facilitate machine learning optimization algorithms and applications.
